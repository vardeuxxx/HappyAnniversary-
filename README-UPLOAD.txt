ANNIVERSARY WEBSITE - GITHUB PAGES UPLOAD

1. Extract this ZIP file on your computer.
2. Open your GitHub repository: vardeuxxx/our-first-anniversary
3. Click Add file > Upload files.
4. Upload index.html AND the entire images folder (keep the folder name "images").
5. Commit the changes to the main branch.
6. Wait for GitHub Pages to publish, then refresh your website.

IMPORTANT:
- Keep index.html beside the images folder.
- Do not rename the images folder or the image files.
- The photos are now part of the website, so visitors can see them on other devices.
- The memory cards and letter are static website content. Editing the HTML and uploading it again is how to change shared content.
